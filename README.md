# 🚗 Car Rental Management System

A full-stack **Car Rental Management System** built with **Node.js**, **Express.js**, **MySQL**, and modern web technologies. This application allows customers to browse available cars, book test drives, rent vehicles, manage their profiles, and request vehicle services through an easy-to-use interface.

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/car_rental.git
```

### 2. Navigate to Project Folder

```bash
cd car_rental
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file and add your configuration:

```env
PORT=3000

DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=car_rental
```

### 5. Start the Application

```bash
npm start
```

or

```bash
node app.js
```

Application will run at:

```
http://localhost:3000
```
